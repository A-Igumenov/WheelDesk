## Kaip sugeneruoti iš naujo

Vaizdus sukuria [`scripts/capture-doc-images.py`](../../scripts/capture-doc-images.py):

```bash
npm run build
npx vite preview --port 4173 --strictPort &
pip install playwright pillow
python -m playwright install chromium
python3 scripts/capture-doc-images.py          # įrašo į docs/images
```

Pastabos:

- Skriptas valdo sąsają klaviatūra lygiai kaip naudotojas (rodyklės, Enter, Esc).
- Laikrodžiai, kalendorius ir istorija priklauso nuo dabartinės datos ir laiko, todėl kiekvieną kartą skiriasi.
- `alarm-ringing.png` daromas rankomis: sukurkite žadintuvą kitai minutei ir palaukite.
- Pakeitę meniu, paleiskite skriptą iš naujo ir peržiūrėkite vaizdus prieš įkeldami pakeitimus.
- Failų pavadinimų nekeiskite: į juos nurodo abu README.

## Susitarimai

- Ekrano vaizdai apkerpami iki 320 × 240 ekrano su rėmeliu; viso įrenginio vaizdai palieka permatomą foną.
- Failai vadinami pagal ekraną (`radio-countries.png`), mažosiomis raidėmis su brūkšneliais.
- Kiekvieną naują vaizdą įrašykite į lentelę **abiejose** šio failo kalbinėse versijose.
